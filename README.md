# English Buddy 🦉 — رفيق الإنجليزي

تطبيق تعليمي تفاعلي لتعليم اللغة الإنجليزية لطلاب الصف الأول حتى الرابع، بأسلوب الألعاب التعليمية الممتعة.

## ✨ الميزات
- اختيار المستوى (الصف 1-4) عند أول تشغيل، يُحفظ تلقائيًا على الجهاز
- خريطة تعلم بوحدات ودروس لكل صف
- 3 أنماط تعلم تفاعلية لكل وحدة:
  - **بطاقات تعليمية (Flashcards)**: تُقلب باللمس، مع نطق صوتي للكلمة
  - **لعبة التوصيل (Matching)**: وصّل الكلمة برمزها
  - **اختبار سريع (Quiz)**: اختيار من متعدد مع تغذية راجعة فورية
- نظام نجوم (0-3) وتقدّم محفوظ محليًا لكل درس
- شاشة "تقدّمي" لعرض الإنجاز الكلي
- واجهة عربية كاملة (RTL) مع محتوى تعليمي إنجليزي

## 📁 البنية التقنية
```
lib/
 ├── main.dart
 ├── core/          # الثيم، الثوابت، إعداد التنقل (go_router)
 ├── models/        # نماذج البيانات (صف، وحدة، درس، كلمة، سؤال)
 ├── services/       # التخزين المحلي، النطق الصوتي، المحتوى التعليمي
 ├── providers/     # إدارة الحالة عبر Riverpod
 ├── screens/       # كل شاشة في مجلد مستقل
 └── widgets/       # عناصر واجهة قابلة لإعادة الاستخدام
```

## 🚀 خطوات التشغيل
1. تأكد من تثبيت [Flutter SDK](https://docs.flutter.dev/get-started/install)
2. داخل مجلد المشروع، نفّذ:
   ```bash
   flutter pub get
   ```
3. شغّل التطبيق على جهاز/محاكي متصل:
   ```bash
   flutter run
   ```
4. (اختياري) لتوليد نسخة ويب:
   ```bash
   flutter run -d chrome
   ```

## ⚠️ ملاحظة مهمة حول المحتوى
محتوى **الصف الأول** مفصّل بالكامل (6 وحدات × 3 دروس) كنموذج عملي جاهز.
محتوى **الصفوف 2-4** جاهز هيكليًا (عناوين الوحدات فقط) في `lib/services/content_service.dart`،
ويحتاج تعبئة بنفس نمط الصف الأول (استخدام دالة `_buildStandardLessons`).

كما أن المفردات والجمل الحالية مبنية على مواضيع شائعة لمستوى الصف الأول في تعليم اللغة الإنجليزية للمبتدئين،
وليست منقولة حرفيًا من الكتاب المدرسي الرسمي لمنهاج التربية والتعليم الفلسطيني. يُنصح بمراجعتها
أو تزويدي بقوائم الكلمات الدقيقة من الكتاب المدرسي لضبط المطابقة الكاملة.

## 🔮 تحسينات مستقبلية مقترحة
- تعبئة محتوى الصفوف 2-4 بالكامل
- دعم لغتين للواجهة (عربي/إنجليزي) عبر `easy_localization`
- إشعارات تذكير يومية للمراجعة
- وضع ليلي (Dark Mode)
- ألعاب إضافية: ترتيب الحروف، الإملاء الصوتي (Spelling)
- مزامنة التقدّم عبر حساب (Firebase) لدعم أكثر من جهاز
- شهادات إنجاز قابلة للمشاركة عند إتمام صف كامل
